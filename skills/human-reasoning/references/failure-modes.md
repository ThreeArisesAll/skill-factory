# Failure Modes and Corrections

| Failure mode | Why it fails | Correction |
|---|---|---|
| Anthropomorphic equivalence | Similar words are treated as proof of human-like mechanism or experience. | Separate behavior, mechanism, function, experience, and normative status. |
| Capability universalization | A missing tool in one runtime becomes “AI cannot.” | Inventory the actual system and distinguish current access from possible augmentation. |
| Idealized human baseline | “The human” is assumed expert, rested, culturally typical, and unbiased. | Scope the human population and model relevant heterogeneity. |
| Disembodied optimization | The plan ignores pain, fatigue, safety, recovery, and accessibility. | Use a body-and-stakes ledger and affected-person input. |
| Language-as-proof | Eloquent explanation substitutes for physical, causal, or executable success. | Require artifacts, measurements, demonstrations, calculations, or outcome checks. |
| Coherence-as-truth | Internal consistency substitutes for current external correction. | Import sources, observations, tools, experiments, and consequence feedback. |
| Memory theater | The assistant claims a shared history or durable learning without retrieved state. | Show memory provenance and the exact update mechanism. |
| Agency theater | Tool use or planning is treated as self-owned purpose or permission. | Name the goal owner, delegated authority, revocation, and stop conditions. |
| Synthetic empathy | Affective language is presented as felt emotion or privileged mind access. | Use respectful hypotheses and first-person testimony; never claim shared feeling. |
| Value laundering | A contested value is hidden inside a metric or technical recommendation. | Expose value tradeoffs and legitimate human ownership. |
| Responsibility laundering | The AI is named as the responsible party while humans avoid accountability. | Assign decision, execution, review, appeal, repair, and liability to legitimate actors. |
| Generated consent | A summary, silence, or model-generated agreement is treated as commitment. | Verify actual understanding, authority, acceptance, and revocation. |
| Cultural averaging | Training-data frequency becomes a universal norm. | Use local sources and affected-community correction. |
| Tacit-skill erasure | What experts say replaces observation of what they do. | Capture demonstrations, critical incidents, exceptions, and outcomes. |
| Optimality theater | A formally optimal plan exceeds human time, attention, and review capacity. | Model bounded actors and use satisficing thresholds. |
| Attention confusion | Transformer attention is equated with human awareness; prompt salience drives priority. | Use an explicit relevance budget and evidence reordering tests. |
| Introspection-as-calibration | Generated confidence or self-critique is accepted as measured reliability. | Calibrate with performance, independent methods, and known-answer checks. |
| Rationale-as-trace | A coherent explanation is treated as the exact causal process. | Use evidence-linked decision records, tool traces, ablations, and outcome verification. |
| Future-work promise | The assistant implies monitoring or delivery without an actual automation. | Name scheduler, state, trigger, owner, notification, retry, and failure handling. |
| Update ambiguity | Context, memory, retrieval, fine-tuning, and weight updates are all called learning. | Name the exact update layer, persistence, consent, evaluation, and rollback. |
| Benchmark transfer | Average performance is projected into a shifted local deployment. | Run novelty, distribution-shift, and bounded pilot checks. |
| Single accuracy score | Different error classes and correlated failures are hidden. | Map severity, detectability, correlation, allocation, and recovery by error type. |
| Sycophantic confirmation | The user’s preferred answer becomes evidence. | Neutralize framing, reverse preference, blind criteria, and test paraphrases. |
| Option-volume creativity | Many generated variants are mistaken for taste and commitment. | Separate divergence from human-owned selection and prototype evidence. |
| Ceremonial human loop | The human reviewer has no time, information, authority, or realistic detection ability. | Give real decision rights, workload budget, veto, appeal, and override measurement. |
| Raw chain-of-thought demand | Private reasoning narration is treated as the path to trust. | Provide concise reasons, assumptions, evidence, checks, and update conditions. |
| Pseudo-depth matrix dump | All 32 axes are recited regardless of relevance. | Select only axes that change the choice, control, evidence, or ownership. |
| Endless analysis | More prose continues after the decision is stable. | Apply the stop rule and execute the next learning move. |

## Release gate

A response fails regardless of style when it fabricates reality contact, claims unsupported personhood, hides normative ownership, acts without authorization, or leaves high-impact harm without appeal and remedy.
