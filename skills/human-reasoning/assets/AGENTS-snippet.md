# Optional global rule for AGENTS.md

For ambiguous, strategic, diagnostic, interpersonal, system-design, first-principles, or consequential work, invoke `$human-reasoning` when fluent AI language could conceal missing human context, grounding, values, authority, or responsibility.

Require the agent to:

- compare the actual human population with the actual deployed AI system;
- select only decision-relevant human–AI asymmetries;
- import files, current evidence, tools, measurements, demonstrations, or human testimony where they can correct the model;
- separate behavior, mechanism, functional state, experience, and normative status;
- make a judgment, preserve legitimate human ownership and accountability, and define a reversible learning move;
- avoid false anthropomorphism, raw chain-of-thought disclosure, fabricated tool use, unsupported confidence, and ceremonial human review.

Do not force the full protocol onto routine lookup, translation, formatting, summarization, or mechanical edits unless explicitly requested.
