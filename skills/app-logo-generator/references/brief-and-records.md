# Brief and Decision Records

Use only the sections that improve the current task. Keep entries concise and label uncertain claims.

## Evidence Labels

- `Observed`: directly inspected in the product, repository, asset, screenshot, or test.
- `User-provided`: stated by the user or an authorized stakeholder but not independently verified.
- `Inferred`: a reasoned interpretation based on named evidence.
- `Unverified`: plausible but unsupported; it must not be used as a proven requirement.

## Semantic Proposition

```text
The mark should express [specific product truth], not merely [generic category trope],
because [evidence]. It should not be read as [dangerous or misleading association].
```

Avoid generic propositions such as “innovative, simple, and technological” unless each term is operationally defined.
